# Organic Curve Generator and Visualizer

An experimental design tool for generating and displaying flowing organic curves. The project is intended for exploring natural-looking paths, decorative geometry, and visual compositions that may be useful in art, fabrication, or modular design.

## Goals

- Generate smooth, organic curve systems
- Visualize curve relationships and flow
- Support experimentation with connected paths and compositions
- Provide a foundation for export or fabrication-oriented workflows

## Status

Early prototype. The core concept is established, but the feature set and usage instructions still need fuller documentation.
